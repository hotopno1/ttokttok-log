똑똑! 설치 안내

Knock-Knock · 보건실 접수 도우미를 우리 학교에 설치하기

똑똑!은 학생이 보건실 앞 태블릿에서 직접 접수하고, 보건 선생님이 PC에서 처치를 기록하는 웹앱이에요. 앱 주소는 모든 학교가 같고, 기록은 학교마다 자기 구글 계정의 파이어베이스(Firebase)에 따로 저장돼요.

  • 걸리는 시간: 처음 한 번, 20~30분
  • 비용: 없어요 (파이어베이스 무료 요금제 Spark)
  • 준비물: 학교 업무용으로 계속 쓸 구글 계정, PC, (학생 화면용) 태블릿
학생 이름·증상·처치 기록은 보건실 비밀번호로 암호화한 뒤에 저장돼요. 파이어베이스에는 알아볼 수 없는 암호문만 남아서, 앱을 만든 사람도 다른 학교 기록을 볼 수 없어요.
1. 파이어베이스 프로젝트 만들기2. 웹앱 등록하고 설정값 받기3. 구글 로그인 켜기 4. 데이터베이스 만들기5. 보안 규칙 붙여 넣기6. 똑똑! 연결하기 7. 태블릿(학생 화면) 연결8. 다른 PC 연결자주 묻는 질문

1파이어베이스 프로젝트 만들기3분

  1. console.firebase.google.com에 학교 업무용 구글 계정으로 로그인해요.
  2. 프로젝트 만들기를 눌러요.
  3. 프로젝트 이름은 학교를 알 수 있게 영어로 지어요. 예: knock-haessal-es
  4. Gemini, Google 애널리틱스를 쓸지 물으면 모두 끄고 넘어가요.
  5. 프로젝트가 만들어지면 계속을 눌러요. 요금제는 기본 Spark(무료) 그대로 둬요.

2웹앱 등록하고 설정값 받기3분

  1. 왼쪽 위 ⚙️ 설정 → 일반으로 가요.
  2. 아래쪽 내 앱에서 </>(웹) 동그라미를 눌러요.
  3. 앱 닉네임에 똑똑을 적어요. "Firebase 호스팅도 설정합니다"는 체크하지 않아요.
  4. 앱 등록을 누르면 const firebaseConfig = { … };가 들어 있는 코드가 나와요. 이 코드를 통째로 복사해서 메모장에 붙여 둬요. 6단계에서 써요.
  5. 콘솔로 이동을 눌러요.
나중에 다시 보려면 ⚙️ 설정 → 일반 → 내 앱에서 SDK 설정 및 구성 → 구성(Config)을 고르면 같은 코드가 나와요.

3구글 로그인 켜기3분

  1. 왼쪽 메뉴 보안 → Authentication에서 시작하기를 눌러요.
  2. Sign-in method 탭에서 Google을 고르고 사용 설정을 켜요. 프로젝트 지원 이메일에 내 계정을 고르고 저장해요.
  3. 같은 화면의 설정 탭 → 승인된 도메인에서 도메인 추가를 누르고 아래 주소를 넣어요. 
    hotopno1.github.io
승인된 도메인을 빠뜨리면 똑똑!에서 로그인 단추를 눌러도 오류가 나요.

4데이터베이스(Firestore) 만들기3분

  1. 왼쪽 메뉴 데이터베이스 및 스토리지 → Firestore에서 데이터베이스 만들기를 눌러요.
  2. 에디션은 Standard, 데이터베이스 ID는 (default) 그대로 둬요.
  3. 위치는 asia-northeast3 (Seoul)을 골라요. 나중에 바꿀 수 없어요.
  4. 보안 규칙은 프로덕션 모드로 시작하고 만들기를 눌러요.
  5. '예약된 백업'을 물으면 고르지 않고 넘어가요. 유료 기능이에요. 백업은 똑똑! 설정 화면에서 파일로 내려받을 수 있어요.

5보안 규칙 붙여 넣기2분

  1. Firestore 화면 위쪽의 규칙 탭을 눌러요.
  2. 들어 있는 글을 모두 지우고, 아래 규칙을 고치지 말고 그대로 붙여 넣어요.
  3. 게시를 눌러요.
rules_version = '2';
// 똑똑! 보건실 접수 도우미 — Firestore 보안 규칙 (모든 학교 공통, 고치지 않고 그대로 붙여 넣어요)
// 처음 로그인해서 '관리 계정'으로 정한 구글 계정과, 그 계정이 더한 '함께 쓰는 계정'만 열 수 있어요.
service cloud.firestore {
  match /databases/{database}/documents {
    function ownerPath() { return /databases/$(database)/documents/meta/owner; }
    function signedIn() { return request.auth != null; }
    function isMember() {
      return signedIn() && exists(ownerPath()) && (
        request.auth.uid == get(ownerPath()).data.uid ||
        (request.auth.token.email_verified == true &&
         request.auth.token.email.lower() in get(ownerPath()).data.emails)
      );
    }

    match /meta/owner {
      allow read: if signedIn() && (!exists(ownerPath()) || isMember());
      allow create: if signedIn()
        && request.resource.data.uid == request.auth.uid
        && request.resource.data.emails is list;
      allow update: if signedIn()
        && resource.data.uid == request.auth.uid
        && request.resource.data.uid == resource.data.uid
        && request.resource.data.emails is list;
    }
    match /meta/crypto {
      allow read, create: if isMember();
    }
    match /parts/{id} {
      allow read, write: if isMember();
    }
    match /visits/{id} {
      allow read, write: if isMember();
    }
  }
}
이 규칙은 모든 학교가 똑같이 써요. 똑똑!에 처음 로그인해서 '관리 계정'으로 정한 구글 계정과, 그 계정이 더한 '함께 쓰는 계정'만 기록을 열 수 있어요.

6똑똑! 연결하기5분

똑똑! 열기 → hotopno1.github.io/ttokttok-log
  1. 우리 학교 연결하기 화면에 2단계에서 복사한 firebaseConfig 코드를 통째로 붙여 넣고 연결하기를 눌러요.
  2. Google 계정으로 로그인을 눌러 1단계와 같은 계정으로 로그인해요.
  3. 관리 계정 정하기에서 이 계정으로 정하기를 눌러요. 관리 계정은 나중에 바꿀 수 없어요.
  4. 보건실 비밀번호를 8자 이상으로 만들어요.
  5. 학교 이름을 넣으면 시작이에요. 설정에서 명렬표(엑셀)를 올리고 학생 화면 잠금 번호를 정해 두세요.
보건실 비밀번호는 꼭 따로 적어 두세요. 기록을 이 비밀번호로 잠가서, 잊어버리면 아무도(구글도, 만든 사람도) 되살릴 수 없어요.

7태블릿(학생 화면) 연결5분

  1. PC의 똑똑! 설정 → 학생 화면(태블릿) 연결에 나오는 QR을 태블릿 카메라로 찍어요. QR에 우리 학교 연결 정보가 들어 있어서 붙여 넣기가 필요 없어요.
  2. 태블릿에서 구글 로그인을 하고 보건실 비밀번호를 한 번 넣어요. '이 기기에서 기억하기'를 켜 두면 다음부터 묻지 않아요.
  3. 열린 화면을 홈 화면에 추가하면 '똑똑! 학생' 아이콘이 생겨요.
태블릿 전용 구글 계정을 추천해요. 태블릿에 선생님 개인 계정을 로그인해 두지 않아도 돼요. 새 계정을 하나 만들고, PC의 설정 → 클라우드 연결 → 함께 쓰는 계정에 그 이메일을 먼저 더한 뒤 태블릿에서 그 계정으로 로그인해요.

8다른 PC·휴대폰 연결

PC의 똑똑! 설정 → 클라우드 연결 → 다른 PC·휴대폰 연결에서 주소 복사를 눌러, 그 주소를 다른 기기에서 열어요. 같은 계정(또는 함께 쓰는 계정)으로 로그인하고 보건실 비밀번호를 넣으면 같은 기록을 함께 봐요.

자주 묻는 질문

로그인 단추를 눌렀더니 오류가 나요3단계의 승인된 도메인에 hotopno1.github.io를 넣었는지, Google 로그인을 켰는지 확인해 주세요.
"이 계정으로는 열 수 없어요"가 나와요5단계 보안 규칙을 붙여 넣고 게시했는지 확인해 주세요. 관리 계정이 아닌 계정이면, 관리 계정에서 '함께 쓰는 계정'에 더해 줘야 해요.
보건실 비밀번호를 잊었어요되살릴 방법이 없어요. 설정 화면에서 내려받은 백업 파일이 있다면, 새 파이어베이스 프로젝트를 만들어 다시 연결한 뒤 백업 파일로 되살릴 수 있어요.
돈이 드나요?파이어베이스 무료 요금제(Spark) 안에서 충분히 쓸 수 있어요. 결제 카드를 등록하지 않으면 요금이 나가지 않아요.
인터넷이 끊기면요?'이 기기 자료로 열기'로 계속 쓸 수 있고, 다시 연결되면 그동안 적은 기록을 자동으로 올려요.
백업은 어떻게 하나요?설정 → 자료 보관 → 백업 파일 내려받기. 학기마다 내려받아 학교 컴퓨터에 보관해 두세요. 백업 파일은 암호화되지 않으니 잘 보관해 주세요.
개인정보는 괜찮나요?기록은 기기에서 암호화된 뒤 학교 구글 계정의 파이어베이스에만 저장돼요. 학교 개인정보 보호 담당자에게 '학생 건강 기록을 암호화해 학교 계정 클라우드(구글 Firebase, 서울 리전)에 보관한다'고 미리 공유해 두면 좋아요.
